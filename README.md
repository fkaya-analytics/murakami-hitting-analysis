# Murakami 2026 Hitting Analysis

Interactive Tableau dashboard analyzing Munetaka Murakami’s 2026 MLB hitting performance using Statcast-style metrics and advanced baseball analytics.

**Current data reflects games through May 16, 2026.**
This project will be continuously updated throughout the 2026 MLB season with new game and plate appearance data.

---

## Project Overview

This project explores Murakami’s offensive profile throughout the 2026 MLB season using custom-built datasets and Tableau visualizations.

The dashboards focus on:

* Home run trends
* Pitch type matchup analysis
* Exit velocity distribution
* Launch angle profile
* Barrel zone analysis
* Spray direction tendencies
* Hard-hit contact quality
* Pitch velocity matchup performance

The goal of this project is to better understand Murakami’s power profile, contact quality, and matchup tendencies through baseball analytics and data visualization.

---

## Key Findings (as of May 16, 2026)

* Murakami has generated some of his highest HR rates against cutters and curveballs compared to other pitch types.
* Home runs are concentrated within the ideal Statcast barrel zone, typically above 95 mph exit velocity and between 20–35 degrees launch angle.
* Hard-hit contact rates appear strongest against fastball and cutter variations.
* Most home run contact has been pulled toward the right-field side, showing a strong pull-side power profile.
* Exit velocity trends suggest Murakami handles higher-velocity pitches effectively.
* Launch angle distributions indicate a fly-ball-oriented offensive profile with relatively few weak pop-ups.

## Dashboards

### 1. HR Profile Dashboard

Analyzes Murakami’s home run production and tendencies.

Features:

* HR timeline
* HR by pitch type
* HR spray direction
* Exit velocity vs pitch velocity (HR only)
* KPI summary cards

---

### 2. Contact Quality Dashboard

Visualizes the quality of contact using Statcast-style metrics.

Features:

* Exit velocity histogram
* Launch angle histogram
* Barrel map
* Statcast contact map
* Hard-hit analysis
* Spray direction overview

---

### 3. Pitch Matchup Dashboard

Examines performance against different pitch types and velocities.

Features:

* HR rate by pitch type
* Hard-hit % by pitch type
* Exit velocity vs pitch velocity
* Pitch velocity analysis
* Pitch handedness filters
